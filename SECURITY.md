# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.1.x (Mobile) | :white_check_mark: |
| 1.0.x (Desktop) | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in Lilt, please do **NOT** open a public issue.

Instead, please send an email describing the vulnerability, steps to reproduce, and impact to:
* **Contact:** [shashankatthaluri on GitHub](https://github.com/shashankatthaluri)

We will respond promptly, acknowledge receipt, and coordinate a patch and release before public disclosure.
